PLAN A: INDUSTRY-LEVEL APPROACH
================================================================================

LEVEL: Enterprise-Grade, Production-Ready, Highly Scalable

1. THEME SYSTEM ARCHITECTURE
   ========================

   Directory Structure:
   src/
   ├── contexts/
   │   └── ThemeContext.js              (Global theme state management)
   ├── hooks/
   │   ├── useTheme.js                  (Custom hook for theme access)
   │   └── useThemeToggle.js            (Toggle functionality)
   ├── themes/
   │   ├── lightTheme.js                (Light mode colors & tokens)
   │   ├── darkTheme.js                 (Dark mode colors & tokens)
   │   ├── themeConfig.js               (Unified theme configuration)
   │   └── tokens.js                    (Design tokens: spacing, sizing)
   ├── styles/
   │   ├── globals.css                  (CSS custom properties)
   │   ├── theme-transitions.css        (Smooth theme change animations)
   │   ├── components.css               (Component styling)
   │   └── animations.css               (Keyframe animations)
   └── components/
       ├── ThemeToggle.js               (Toggle button component)
       └── ThemeProvider.js             (Context provider wrapper)

   Implementation Strategy:
   - Use Context API + useReducer for scalable state management
   - Implement CSS Custom Properties (CSS Variables) for dynamic theming
   - localStorage for theme persistence across sessions
   - System preference detection (prefers-color-scheme) as fallback
   - Smooth transitions between themes (0.3s duration)
   - TypeScript support for type safety

   Hero Features to Implement:
   - Image Carousel: Books rotating with smooth 3D perspective effect
   - Parallax Scrolling: Background layers move at different speeds (15%, 25%, 35%)
   - Entrance Animations: Staggered reveals on page load (200ms between elements)

PLAN B: STARTUP-LEVEL APPROACH
================================================================================

LEVEL: MVP, Quick Implementation, Pragmatic Choices

1. QUICK THEME TOGGLE (MINIMAL BUT FUNCTIONAL)
   ============================================

   Minimal Implementation:
   - Single useTheme hook with useState
   - localStorage for persistence
   - CSS class switching (.light-theme / .dark-theme)
   - 5-10 CSS variable overrides
   - No Context API complexity

   Time Investment: 2-3 hours

   Implementation Steps:
   1. Create useTheme.js hook:
      - State for theme (light/dark)
      - Toggle function
      - localStorage integration
      - System preference detection

   2. Add CSS variables:
      :root { --primary: #4F46E5; --surface: #FFFFFF; }
      [data-theme="dark"] { --primary: #818CF8; --surface: #0F172A; }

   3. Create ThemeToggle.js component:
      - Simple button with icon
      - onClick handler calls useTheme().toggle()
      - Place in Navbar

   4. Update existing components:
      - Use CSS variables instead of hardcoded colors
      - Add data-theme attribute to root div

2. HERO ANIMATED IMAGES (QUICK WIN)
   =================================

   Fastest Approach:
   - Leverage existing Framer Motion library
   - Simple image carousel (3-5 book images)
   - CSS keyframes for fade/slide animations
   - Optional: One background GIF or video
   - No complex 3D transforms

   Time Investment: 4-5 hours

   Components Needed:
   ├── AnimatedImageCarousel.js
   │   - State: current image index
   │   - Function: next/prev handlers
   │   - Framer Motion: motion.div with animate prop
   │   - Buttons: Previous, Next navigation
   │
   ├── HeroImage.css
   │   - @keyframes slideIn, fadeOut
   │   - Smooth transitions (0.5s)
   │   - Mobile responsive adjustments
   │
   └── Hero.js (updated)
       - Replace static image with carousel
       - Integrate animated background

   Implementation:
   - Show 1 image, rotate every 5 seconds
   - Fade transition between images
   - Prev/Next buttons for manual control
   - Auto-play on desktop, manual on mobile

3. STYLING APPROACH: ADD TAILWIND CSS
   ===================================

   Fastest CSS Framework:
   npm install -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p

   Setup Time: 1 hour

   Benefits:
   ✓ Pre-built components
   ✓ Built-in dark mode support (class or system)
   ✓ No custom CSS writing
   ✓ Responsive utilities (sm:, md:, lg:)
   ✓ Large community + plugins
   ✓ Production bundle is smaller

   Configuration:
   - Enable dark mode: darkMode: 'class'
   - Custom colors: Extend default theme
   - Purge unused CSS: Automatic in production

   Migration Time: 2-3 hours for existing components
   (Update className attributes, remove old CSS)

   Alternative: Keep Bootstrap + add CSS modules
   (If you prefer minimal change)

4. FEATURE PRIORITY FOR MVP
   =========================

   Must-Have (Core Features):
   ✓ Theme toggle button (light/dark)
   ✓ localStorage persistence
   ✓ Hero image carousel (5 images)
   ✓ CSS transitions for theme switch

   Nice-to-Have (Phase 2):
   ○ System preference detection
   ○ Parallax effects
   ○ Advanced animations
   ○ Image optimization

   Out of Scope (Future):
   × Canvas/WebGL animations
   × Full design system
   × Advanced performance optimization
   × Comprehensive testing
