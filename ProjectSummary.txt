PROJECT OVERVIEW
================================================================================
Online Book Exchange Platform is a comprehensive full-stack web application built with 
the MERN stack (MongoDB, Express, React, Node.js). It creates a vibrant community 
platform where book lovers can lend, sell, and discover new books. The application 
demonstrates a complete development lifecycle with secure authentication, real-time 
communication, local image uploads, and an interactive responsive UI.

PROJECT NAME: OnlineBookExchangePlatform-mern-app
APPLICATION TYPE: Web Application (MERN Stack)
STATUS: Fully Functional with Build Artifacts

DATABASE MODELS
================================================================================

USER MODEL:
  - email: String (unique)
  - password: String (hashed with bcryptjs)
  - firstName: String
  - lastName: String
  - city: String
  - state: String
  - profilePicture: String (Local upload path)
  - ratings: Array (User ratings received)
  - averageRating: Number (Calculated from ratings)
  - createdAt: Timestamp

BOOK MODEL:
  - title: String
  - author: String
  - description: String
  - type: Enum (Lend/Sell)
  - price: Number (If type is Sell)
  - condition: Enum (New/Good/Fair/Poor)
  - bookCover: String (Local upload path)
  - owner: Reference to User
  - status: Enum (Available/Exchanged/Pending)
  - createdAt: Timestamp

REQUEST MODEL:
  - book: Reference to Book
  - requester: Reference to User
  - owner: Reference to User
  - status: Enum (Pending/Accepted/Sent/Received/Completed/Rejected)
  - createdAt: Timestamp
  - updatedAt: Timestamp

MESSAGE MODEL:
  - conversation: Reference to Conversation
  - sender: Reference to User
  - text: String
  - createdAt: Timestamp

CONVERSATION MODEL:
  - participants: Array of User References
  - request: Reference to Request
  - messages: Array of Message References
  - createdAt: Timestamp
  - updatedAt: Timestamp

   - My Books: View and manage personal book listings

   - Wishlist: Save favorite books for future reference

================================================================================
APPLIED PROJECT MODULES: OBJECTIVES & IMPLEMENTATION
================================================================================

1. USER AUTHENTICATION & SESSION SECURITY MODULE (CORE & SECURITY):
   - Objective:
     Establish a secure environment for community exchanges. Register user accounts with 
     validated inputs, secure passwords, handle state-free login requests, protect API 
     routes against unauthorized access, and persist active logins for user convenience.
   - Core File(s):
     * backend/models/User.js (Data Structure)
     * backend/routes/authRoutes.js (Authentication endpoints)
     * backend/middleware/authMiddleware.js (Access interceptor)
     * frontend/src/components/Register.js & Login.js (UI Forms)
   - Implementation Details:
     * User registration validates unique email patterns and encrypts passwords using 
       bcryptjs (salt rounds: 10) before storage in MongoDB.
     * Login generates a JSON Web Token (JWT) signed with a server secret (`JWT_SECRET`) 
       which encodes the user's ID, email, and username.
     * Client stores this token in localStorage and attaches it to the HTTP 'Authorization' 
       header (Bearer scheme) for subsequent authenticated API requests.
     * authMiddleware.js intercepts requests to protected endpoints, verifies the token's 
       signature, and attaches the validated user payload to the request object.

2. BOOK CATALOG & LISTING OPERATIONS MODULE (CRUD):
   - Objective:
     Enable users to share and manage books they wish to exchange. Allow listing, 
     editing, and deletion of books, including file uploads for covers, price settings 
     for sales, and filtering options.
   - Core File(s):
     * backend/models/Book.js (Data Schema)
     * backend/routes/bookRoutes.js (API Endpoints)
     * backend/config/upload.js (Multer middleware config)
     * frontend/src/components/AddBook.js & BrowseBooks.js (UI Listing/Browsing)
   - Implementation Details:
     * MongoDB tracks listing details: Title, Author, Type (Lend/Sell), Price, Condition, 
       Owner ID, and Listing Status (Available, Pending, Exchanged).
     * Multer middleware configures local image uploads on the server, saving files 
       directly into backend/uploads/ directory for local retrieval.
     * BrowseBooks.js lists available books, providing search inputs to query target records.
     * MyBooks.js fetches books filtered by the user's ID and allows updating details or deleting listings.

3. BOOK TRANSACTION & EXCHANGE WORKFLOW MODULE (BUSINESS LOGIC):
   - Objective:
     Provide a clear step-by-step transaction model for exchanging books. Automate state 
     changes as books are requested, sent, received, and finalized.
   - Core File(s):
     * backend/models/Request.js (Transaction Schema)
     * backend/routes/requestRoutes.js (Workflow Controller)
     * frontend/src/components/Requests.js (Transactional Dashboard)
   - Implementation Details:
     * Tracks the exchange lifecycle using status codes: Pending -> Accepted -> Sent -> Received -> Completed.
     * Requesters submit requests, creating a new `Request` record that is pending review by the owner.
     * The owner can Accept or Reject the request.
     * Once accepted, the owner updates status to "Sent" (shipped). The requester then marks it as 
       "Received" (delivered), automatically completing the transaction.
     * Upon completion, the Book status in MongoDB is updated to "Exchanged" to remove it from browse page queries.

4. REAL-TIME COLLABORATION & INSTANT CHAT MODULE (COMMUNICATION):
   - Objective:
     Facilitate quick communication between exchange partners. Automatically open communication channels 
     on transaction updates, letting users chat instantly and coordinate delivery logistics.
   - Core File(s):
     * backend/server.js (Socket.IO initialization & events)
     * backend/models/Message.js & Conversation.js (Chat History Schemas)
     * frontend/src/components/ChatModal.js (Interactive Chat UI)
   - Implementation Details:
     * Setting up a request acceptance automatically generates a new `Conversation` referencing the exchange ID.
     * Socket.IO integrates with Node's HTTP server, managing connections from front-end clients.
     * Users join chat rooms named after the corresponding Conversation ID.
     * Sending messages saves them to MongoDB and broadcasts them to the active room using `io.to(room).emit()`.
     * ChatModal.js fetches history on mount and updates the chat feed dynamically as messages arrive.

5. USER REPUTATION & DYNAMIC REVIEW MODULE (SOCIAL TRUST):
   - Objective:
     Promote a safe, friendly exchanging environment by allowing readers to review and rate each other.
   - Core File(s):
     * backend/models/User.js (Holds rating array & average rating)
     * backend/routes/userRoutes.js (Rate user endpoint)
     * frontend/src/components/RatingModal.js & StarRating.js (Review Modal & Rating Bar)
   - Implementation Details:
     * Ratings are logged inside User profiles as objects: `{ rating: Number, comment: String, rater: UserID }`.
     * Dynamic average ratings are calculated on new reviews: `averageRating = sum(ratings) / count(ratings)`.
     * RatingModal.js shows up upon completion of a transaction, prompting the user for a score and comment.
     * StarRating.js renders stars based on rating values, showing review history on Profile.js.

6. DYNAMIC COLOR THEMING & SYSTEM PERSISTENCE MODULE (UI/UX):
   - Objective:
     Provide a modern user interface that switches between light and dark modes, reducing eye strain and matching OS defaults.
   - Core File(s):
     * frontend/src/hooks/useTheme.js (Context provider & hook)
     * frontend/src/components/ThemeToggle.js (Toggle UI Component)
     * frontend/src/index.css (Global design tokens & styles)
   - Implementation Details:
     * React Context API exposes a theme state ('light' | 'dark') and a toggleTheme callback.
     * Defaults to the user's OS setting via `window.matchMedia('(prefers-color-scheme: light)')`.
     * Saves selected preferences to local storage under `bookexchange-theme`.
     * Applies a `data-theme` attribute to the root HTML element, changing variables in index.css.
     * Theme transitions are smoothed using CSS variables (0.3s transition).
     * Toast notifications update style dynamically based on the current theme state.

7. PREMIUM INTERACTIVE HERO CAROUSEL & ASSET MANAGEMENT MODULE (UI/UX):
   - Objective:
     Introduce the platform with high-impact, thematic slides. The carousel contains play/pause controls, progress indicators, and keyboard navigation.
   - Core File(s):
     * frontend/src/components/HeroImageCarousel.js (Component)
     * frontend/src/components/Home.js (Landing Page incorporation)
     * frontend/src/assets/hero-1.png ... hero-5.png (Slide Assets)
   - Implementation Details:
     * Features 5 illustrative slides detailing exchange concepts.
     * Slides transition using horizontal slides, scaling, and opacity blends.
     * Employs spring physics parameters (stiffness: 200, damping: 28) for smooth slide motion.
     * Progress bar tracks remaining time using a requestAnimationFrame loop (5-second intervals).
     * Pauses autoplay on hover, supports Arrow keys for navigation, and Spacebar for play/pause toggles.

8. DYNAMIC MOTION & MICRO-INTERACTION EFFECTS MODULE (UI/UX):
   - Objective:
     Provide a responsive, high-end look and feel using micro-animations.
   - Core File(s):
     * frontend/src/components/ThemeToggle.js
     * frontend/src/components/Home.js
     * frontend/src/index.css
   - Implementation Details:
     * Toggle buttons use scale gestures (`whileTap={{ scale: 0.88 }}` and `whileHover={{ scale: 1.08 }}`).
     * Sun and Moon icons transition via exit-entry rotation keyframes (+90deg / -90deg rotation).
     * Page elements stagger on-scroll into view.
     * Floating cards move dynamically to add visual depth to the landing page.
     * Glass cards expand, increase border opacity, and show glowing shadows on hover.

API ENDPOINTS (BACKEND)
================================================================================

AUTHENTICATION ROUTES (/api/auth):
  POST /register          - Register new user account
  POST /login             - Login user and return JWT token
  POST /verify-token      - Verify JWT token validity

BOOK ROUTES (/api/books):
  GET /                   - Get all available books
  GET /:id                - Get specific book details
  POST /                  - Create new book listing (authenticated)
  PUT /:id                - Update book details (authenticated)
  DELETE /:id             - Delete book listing (authenticated)
  GET /user/:userId       - Get books by specific user

REQUEST ROUTES (/api/requests):
  GET /                   - Get user's requests (incoming/outgoing)
  POST /                  - Create new book request
  PUT /:id                - Update request status (Accept/Reject/Mark Sent/Confirm Receipt)
  DELETE /:id             - Cancel request

MESSAGE ROUTES (/api/messages):
  GET /conversation/:conversationId - Get messages in conversation
  POST /                  - Send new message
  GET /conversations      - Get user's conversations

USER ROUTES (/api/users):
  GET /:id                - Get user profile details
  PUT /:id                - Update user profile
  POST /:id/rate          - Add rating/review for user
  GET /:id/ratings        - Get user's ratings

WISHLIST ROUTES (Integrated):
  POST /wishlist          - Add book to wishlist
  GET /wishlist           - Get user's wishlist
  DELETE /wishlist/:id    - Remove book from wishlist

SETUP & INSTALLATION INSTRUCTIONS
================================================================================

PREREQUISITES:
  - Node.js (v14 or higher)
  - npm (v6 or higher)
  - MongoDB (Local installation or Atlas)

STEP 1: Clone Repository
  git clone <repository-url>
  cd OnlineBookExchangePlatform-mern-app

STEP 2: Backend Setup
  cd backend
  npm install
  
  Create .env file with:
    MONGODB_URI=mongodb://127.0.0.1:27017/bookExchangeDB
    JWT_SECRET=<your-secret-key>
    PORT=5000
  
  npm run dev  (Starts backend on port 5000)

STEP 3: Frontend Setup
  cd ../frontend
  npm install
  npm start   (Starts frontend on port 3000)

STEP 4: MongoDB Setup
  - Ensure MongoDB is running locally
  - Database will auto-create on first connection
  - Verify connection: mongodb://127.0.0.1:27017/bookExchangeDB

PRODUCTION BUILD:
  Frontend: npm run build   (Creates optimized build in frontend/build/)
  Backend: Ensure environment variables are set for production
